# OG2 artwork masters

Nine original AI-generated illustrations created for `/og2`, inspired by
the local OG comic panels and the unlocked First Blood cover. These are
creative interpretations for the fan experience, not production stills.

| Master | Role |
| --- | --- |
| `katana-world.png` | Rain-soaked temple courtyard, red moon, distant opponents |
| `katana-hero.png` | OG performing a sweeping katana cut; transparent |
| `archery-world.png` | Misty bamboo forest with archery targets at varying distances |
| `archery-hero.png` | OG drawing a Japanese bow; transparent |
| `bushido-world.png` | Mountain training ground, rope bridge, dragon sky |
| `bushido-hero.png` | OG in a leaping martial-arts pose; transparent |
| `bushido-virtues.png` | Hanging Courage, Justice, and Respect scrolls from the Bushido game; transparent |
| `dragon.png` | Vermilion spirit dragon; transparent |
| `foreground.png` | Pine, lantern, rocks, leaves, and mist; transparent |

Shared art direction: angular black comic inks, etched crosshatching,
petrol-blue shadow planes, muted ivory, and vermilion rim light. Character
references use the OG cover and comic likeness. Environments leave space
for independently animated characters and foreground elements.

Production encodings are in `apps/web/public/og2/` as WebP at quality 86
with alpha quality 95. PNG originals are preserved here for future edits.
